# 7. Plan de Fases y Plan de Desarrollo de Software

## 7.1 Cronograma y Distribución de Esfuerzo en UP

```
CRONOGRAMA DE FASES EN EL PROCESO UNIFICADO (12 Semanas Totales)

Fase 1: INICIO (Inception) - 2 Semanas [Actual]
  ├── Iteración I1: Definición de Visión, Casos de Uso, FURPS+ y Riesgos.
  └── Entregable: Documento Consolidado de Requisitos e Inception.

Fase 2: ELABORACIÓN (Elaboración) - 4 Semanas
  ├── Iteración E1: Arquitectura Núcleo, POO, BD y Calculadora de Gramaje (CU01, CU02, CU04).
  ├── Iteración E2: Módulo de Diario Alimentario y Balance Diario (CU03, CU05, CU06).
  └── Entregable: Arquitectura Ejecutable y 80% de Casos de Uso Críticos.

Fase 3: CONSTRUCCIÓN (Construction) - 4 Semanas
  ├── Iteración C1: Módulo de Alimentos Personalizados e Historial (CU07, CU08).
  ├── Iteración C2: Pulido de Interfaz de Usuario, Validaciones y Optimización de Rendimiento.
  └── Entregable: Sistema Fuely Funcional.

Fase 4: TRANSICIÓN (Transition) - 2 Semanas
  ├── Iteración T1: Pruebas de Aceptación de Usuario, Corrección de Defectos y Despliegue.
  └── Entregable: Producto Final Entregado en Producción con Manual de Usuario.
```

## 7.2 Recurso Humano y Entorno de Desarrollo
- **Equipo de Desarrollo:** 1 Desarrollador / Arquitecto de Software
- **Esfuerzo Estimado Total:** 240 horas distribuidas en 12 semanas (20 horas/semana).
- **Entorno Tecnológico:**
  - *Lenguaje:* Java 17 LTS / Python 3.10+.
  - *IDE:* Visual Studio Code.
